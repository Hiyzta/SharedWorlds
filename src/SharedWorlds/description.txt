Shared Worlds lets a group of friends share one Terraria world.

Every participant gets their own private (friends-only) Steam Workshop item for the world. While a world is live, the host updates that same item on the 10-minute autosave timer, and connected clients receive the snapshot for instant host recovery. Steam friends, lobbies and peer-to-peer multiplayer still do the actual networking; this mod only decides where the newest world file lives.

Features:
- Real "Play Shared Worlds" row in the multiplayer menu
- Clean Play screen with live host/player count, last-saved timestamps and sync state
- Join an online shared world, or host the latest saved snapshot
- Shared worlds are kept on the hosted path: opening one in single-player is rejected the same way vanilla blocks Journey-mode mismatches
- Configurable 10-minute Shared Worlds autosave upload while hosting
- Host-left prompt with a rehost election and automatic rejoin
- Per-account Workshop storage (friends-only)
- Timestamped snapshot history, hash verification and local backups
- A vanilla-styled Steam Workshop agreement notice before your first play/register/import, with skip and don't-remind options
- Fork detection instead of silent overwrites
- Peer-to-peer snapshot transfer during a session

The original creator is not special: anyone in the group can host and make progress.
